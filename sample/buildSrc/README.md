# sample/buildSrc/

This directory is generated by `.omp/bootstrap-mutation-testing.sh`.

It contains the typed `MutationResults` module — `@Serializable` data classes
and pure parser functions — that the `mutation-results.gradle.kts` task
delegates to. The Kotlin version in `build.gradle.kts` is substituted
from the target project's Kotlin Gradle plugin version by the bootstrap script.

Do not edit these files directly. To regenerate:

```bash
# From this project's root:
.omp/bootstrap-mutation-testing.sh .
```

For setup instructions, see `docs/how-to/manual-setup.md`.
